# 一张图片怎样变成一百个分数

上一章把 MNIST 图片展成 784 个数字，再交给全连接层。像素一个不少，但全连接层没有特别照顾图片的行列关系：挨在一起的两个像素和相隔很远的两个像素，都各自通过一个权重连到隐藏单元。换成 `32×32` 的彩色图片后，输入有 `3×32×32=3072` 个数，仅仅接到 128 个隐藏单元，就需要 `3072×128=393216` 个权重，还没有算偏置。

图片还有一个很有用的规律：一条边缘无论出现在左边还是右边，附近的亮暗变化都差不多。卷积把这个规律写进网络，只看附近的一小块，并让同一组权重在整张图上重复使用。这一章仍从能手算的数字开始，先算一个窗口，再让它滑过图片；局部运算理清以后，BatchNorm、残差连接和分类头才依次接进来。

## 彩色图片多了哪一维

CIFAR-100 的图片大小为 `32×32`，每张图有红、绿、蓝三个通道。本仓库统一使用 NCHW 排列：

```text
一张图片      (C,H,W)   = (3,32,32)
8 张图片一批  (N,C,H,W) = (8,3,32,32)
```

<div class="widget-mount" data-widget="image-batch"></div>

原始像素通常是 0 到 255 的整数。数据进入模型前先除以 255，再按预先固定的通道均值和标准差做标准化。假设某个像素缩放后为 0.8，对应通道的均值是 0.5、标准差是 0.2，那么它会变成：

$$
\frac{0.8-0.5}{0.2}=1.5
$$

所以标准化后的图片会出现负数，也会出现大于 1 的数。本仓库采用预设的 CIFAR-100 通道常数，具体取值在[数据管线](../exercises/block_02_resnet/task_10_image_data_pipeline/README.md)中；程序不会随抽样数量重新估计它们。换用自己的数据时，可以只在训练 split 上计算一次，再让训练、验证和测试共用这组数。若各算各的，同一种像素值就可能被变换成不同的输入。

训练图片还会随机裁剪和水平翻转。它们改变的是同一张图的呈现方式，标签不变。验证和测试不做随机增强，否则同一个模型每次评估会遇到不同输入，结果不方便比较。

## 一个窗口怎样得到一个数

先不管颜色，只看一个 `3×3` 灰度窗口。数值越大，位置越亮：

```text
窗口 X                 权重 K
[ [3, 2, 0],           [ [1, 0, −1],
  [3, 2, 0],             [1, 0, −1],
  [3, 2, 0] ]            [1, 0, −1] ]
```

把同一位置的数字相乘后相加：

```text
第一行  3×1 + 2×0 + 0×(−1) = 3
第二行  3×1 + 2×0 + 0×(−1) = 3
第三行  3×1 + 2×0 + 0×(−1) = 3
总和                              9
```

左右一样亮时，正负两列会抵消；明暗方向反过来，结果会变成负数。这组手写权重因此会响应竖直的亮暗交界。把它在图上逐格滑动，每到一个位置就算一次，再按位置排好结果，便得到一张特征图。训练中的卷积核并非事先指定，它会像全连接层的权重一样，随着分类损失更新。

<div class="widget-mount" data-widget="conv-sweep"></div>

这里有两个约束：一个输出只读取附近的窗口；同一个输出通道在所有位置使用同一组权重。前者叫局部连接，后者叫参数共享。边缘换了位置，不需要再学一套检测它的参数。

### 步长和补边改变输出大小

一个 `4×4` 输入放入 `3×3` 窗口，不补边且每次移动一格。窗口左上角横向有两个位置，纵向也有两个位置，所以输出为 `2×2`。

stride 是窗口每次移动的格数，padding 是输入外围补出的格数。高度方向的输出大小为：

$$
H_{out}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1
$$

这里 `H` 是输入高，`K` 是核高，`S` 是步长，`P` 是上下各补几格，`⌊·⌋` 表示向下取整。宽度同理。比如输入高 32、核高 3、padding 1、stride 1，输出仍是 32；若 stride 改成 2，输出高变成 16。最后不足一个完整窗口的部分不会再产生输出，这就是公式里取整的原因。

### RGB 窗口怎样合成一个输出

一个卷积核会同时覆盖三个输入通道。假设红、绿、蓝三个窗口与各自权重相乘后，分别贡献 `2`、`−1`、`4`，再加上 `0.5` 的偏置，该位置的输出就是：

```text
2 + (−1) + 4 + 0.5 = 5.5
```

这一整组跨通道权重只产生一个输出通道；想得到 16 张特征图，就需要 16 组权重：

```text
输入 X  (8, 3,32,32)
权重 W  (16,3, 3, 3)
输出 Y  (8,16,32,32)   # stride=1, padding=1
```

输出的 16 个通道已经不再分别表示红、绿、蓝，而是 16 组卷积核学到的不同响应。虽然一张输出共有 `16×32×32` 个数，这一层却只需要 `16×3×3×3+16=448` 个参数，因为同一组 27 个权重和一个偏置会在所有位置重复使用。图片尺寸变大时，计算量会增加，卷积核的参数量不必跟着增加。

### 只看 3×3，怎样认出完整物体

一个窗口确实看不见整只动物，但后面的卷积读取的是前一层的特征图。先只看宽度方向：第一层的某个输出读取原图中连续 3 个位置，第二层再读取第一层相邻的 3 个输出，这三段范围合起来覆盖原图的 5 个位置。高、宽两维一起算，连续两个 stride-1 的 `3×3` 卷积便能关联到 `5×5` 的原图区域，三个则是 `7×7`。这个可能影响当前输出的输入范围叫感受野。

我们也会在卷积之间加入 ReLU，做法与上一章相同。这样后一层既能组合更大范围的信息，也能通过非线性改变表示；只把几次线性运算接起来，仍然只能得到一次线性变换。网络通常从局部的颜色和边缘开始，逐层组合信息，但某个具体通道学到了什么，仍要看训练结果。

## BatchNorm 处理不断变化的数值尺度

卷积层一层层叠加后，各通道的数值范围会随参数更新而变化。BatchNorm 在训练时为每个通道统计当前 mini-batch 的均值和方差；对 NCHW 输入，统计范围是样本轴和两个空间轴。

先用两个数看标准化本身。`[1,3]` 的均值为 2、方差为 1，暂时忽略很小的稳定项，标准化后得到 `[-1,1]`。真实层还会学习缩放 `γ` 和平移 `β`：

$$
\hat{x}=\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}
$$

$$
y=\gamma\hat{x}+\beta
$$

`γ` 和 `β` 让网络不必永远保持零均值和单位方差。

![BatchNorm 的训练与评估状态](../assets/images/batchnorm.png)

一张图片本身也有许多空间位置，可以算出均值和方差；问题是，如果推理时继续用当前 batch 统计，同一张图的预测就会受到同批其他图片的影响。因此层在训练过程中保存均值和方差的移动平均，评估时改用这两组固定的运行统计量。它们不参加梯度下降，却会改变预测结果，所以保存模型时也不能漏掉。这里的统计发生在网络内部的特征图上，与输入图片只做一次的标准化是两件事。

## 空间尺寸在哪里缩小

特征图若一直保持 `32×32`，后面的计算会越来越重。常见的缩小方法有池化和 stride 大于 1 的卷积。MaxPool 会选择每个小窗口中的最大值，例如：

```text
[[1,4],
 [2,3]]  -> 4
```

这个窗口经过 MaxPool 后留下 4，经过 AvgPool 则留下平均值 `2.5`。两者都会丢掉一部分位置细节，只是保留的统计不同。反向传播时，MaxPool 把梯度送回前向最大值所在的位置，AvgPool 则把梯度平均分给窗口中的元素。

<div class="widget-mount" data-widget="pool-sweep"></div>

本章的 `SmallResNet` 不在中途使用 MaxPool，而是在新 stage 的第一个卷积中设置 `stride=2`，边提取特征边把高、宽减半。网络末尾再用 Global Average Pool 对每个通道的整张特征图取平均，把 `(N,C,H,W)` 变为 `(N,C)`。

## shortcut 让原来的表示有路可走

[ResNet 论文的图 1](https://arxiv.org/abs/1512.03385)记录了一个反直觉现象：在 CIFAR-10 上，把普通网络从 20 层加深到 56 层后，训练误差反而升高。这里比较的是训练集，不能用“层数多所以过拟合”解释。既然较浅的网络已经能做到较低的训练误差，增加的层能不能先保留它的结果，再学习需要修改的部分？残差块沿这个想法把输入分成两路：主分支做两次卷积，shortcut 分支尽量原样传递，最后再相加：

$$
z=F(x)+S(x)
$$

$$
y=\operatorname{ReLU}(z)
$$

![残差块的主分支与 shortcut](../assets/images/residual_block.png)

shape 不变时，`S(x)=x`。如果主分支当前没有需要补充的变化，让 `F(x)` 接近 0，就能先保留已有表示。若通道数或空间大小改变，`x` 不能直接相加，shortcut 会用 `1×1` 卷积和 BatchNorm 把 shape 对齐。

相加也改变了梯度的走法。暂时忽略末尾 ReLU，令 `z=x+0.1x`。如果损失对 `z` 的梯度是 2，那么传回 `x` 的梯度是：

```text
2×(1 + 0.1) = 2.2
```

其中一项来自 shortcut，另一项来自主分支。这个小例子只说明多了一条传播路径；真实块中的 ReLU 和卷积仍可能放大、缩小或抵消梯度。

## 把这些层接成 SmallResNet

下面固定使用本章的教学配置：三个 stage 分别有 `8、16、32` 个通道，每个 stage 放一个 BasicBlock。stage 指一组输出通道数和空间大小相同的残差块，stem 则是进入这些块之前的第一组卷积。图片经过网络时，shape 这样变化：

| 位置 | 运算 | 输出 shape |
| --- | --- | --- |
| 输入 | CIFAR-100 batch | `(N,3,32,32)` |
| stem | `3×3 Conv → BN → ReLU` | `(N,8,32,32)` |
| stage 1 | 1 个 identity BasicBlock | `(N,8,32,32)` |
| stage 2 | 首个卷积 stride 2，shortcut 投影 | `(N,16,16,16)` |
| stage 3 | 首个卷积 stride 2，shortcut 投影 | `(N,32,8,8)` |
| pool | 每个通道取空间平均 | `(N,32)` |
| fc | 线性层 | `(N,100)` |

最后的 100 个数是 logits，对应 CIFAR-100 的 100 个细类别。全局平均池化已经把每张图变成长度为 32 的向量，分类头便可以直接复用上一章的 `Linear(32,100)`。它并不预先知道哪个通道代表哪种物体，而是在训练中学会怎样组合这些响应。Softmax 与交叉熵、反向传播和参数更新也与上一章相同；本仓库的交叉熵内部已经包含 Softmax，所以模型返回原始 logits 即可。

```text
model.train()
取一个 minibatch，可选随机增强
forward -> logits -> cross entropy
backward -> optimizer.step()

model.eval()
在 validation 上只做 forward
```

训练指标说明模型能否拟合见过的数据，验证指标说明当前配置在未参与更新的数据上表现怎样。测试集留到配置确定以后再使用。

## 选读：卷积怎样变成矩阵乘法

四层循环可以直接实现卷积，但速度很慢。`im2col` 把每个局部窗口展成一行，再一次完成矩阵乘法。对于 `4×4` 输入、`3×3` 核、stride 1、padding 0，一共有四个窗口，每个窗口九个数：

```text
X_col  (4,9)
W_col  (9,C_out)
Y_col  (4,C_out)
```

![四个窗口展开成矩阵](../assets/images/im2col_explained.png)

$$
Y_{col}=X_{col}W_{col}+b
$$

反向时，权重梯度和窗口梯度仍是上一章的矩阵公式：

$$
dW_{col}=X_{col}^{\mathsf T}dY_{col}
$$

$$
dX_{col}=dY_{col}W_{col}^{\mathsf T}
$$

相邻窗口会共享像素，所以 `dX_col` 不能直接 reshape 成原图。同一个像素在不同窗口中收到的梯度要相加回去。
