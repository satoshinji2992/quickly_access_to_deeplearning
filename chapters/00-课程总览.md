# 从这里开始

这套教程从 $y=ax+b$ 开始。原因很简单：只有两个参数时，预测错在哪里、梯度怎样把参数往回拉，都能用纸笔算完。到了卷积网络和 Transformer，模型的计算变了，但“预测—计算损失—沿梯度更新”这条骨架还在。

![从直线拟合到分类网络](../assets/images/block1_overview.png)

## 三部分分别在算什么

### 一次参数更新

[y = ax + b：神经网络到底是什么？](./01-基础知识.md) 先拟合一条直线，再试着分开圆内外的点。直线做不到时，我们才引入 ReLU 和多层网络；网络变长之后，再用链式法则把梯度一层层传回去。这一段最后会得到一个小型 NumPy 深度学习库，并把同一套训练流程用在 MNIST 上。

### 图片与局部窗口

[一张图片怎样变成一百个分数](./02-ResNet图像分类.md) 从一个 $3\times3$ 窗口开始。同一组权重在图上滑动，就能在不同位置寻找相同的局部模式。接着处理通道、空间尺寸和 BatchNorm，最后才把 shortcut 接进来。这里使用 CIFAR-100：图片分为 100 个细类别，分类头因此输出 100 个分数。

### token 怎样读到前文

[Transformer 语言模型：从文本到下一个 token](./03-Transformer与MiniMind.md) 先把 token（文本切出的小片段）变成向量，再手算一次 Attention。因果遮挡解决“训练时偷看答案”的问题，位置信息告诉模型 token 的顺序。等最小结构连起来后，再看 RoPE、GQA、SwiGLU 和 KV Cache 在其中换了什么。

## 怎样读一节

主章节先用小例子把概念引出来，实现页面紧接着解释代码中的 shape、缓存和反向传播。第一次读，可以在章文讲完一个例子后打开紧接着的实现链接，把公式和文件里的变量对应起来，再回到章文继续。网页侧栏把整章放在前面、实现页面放在后面，方便以后查阅；不需要先记住整章才能打开代码。

交互演示把纸面上的数字变成可以拖动的版本。改一个参数，曲线、边界或权重会怎样变化，可以当场看到。

## 开始前需要什么

能读 Python、知道矩阵乘法、对导数有一点印象，就足够开始；tensor、batch、logits 这些词会在第一次用到时就地解释。仓库里的测试会检查数据隔离、张量 shape 和一次完整的参数更新，真实数据上的效果则仍以训练集与验证集的指标为准。

安装步骤和第一条运行命令在 [仓库首页](../README.md#环境准备)。直线拟合和圆形分类使用随仓库附带的数据；MNIST、CIFAR-100 需要额外下载。卷积和 Transformer 都有能在 CPU 上运行的小样例，完整图像训练与较大文本训练则需要更多时间。
