BEFORE YOU START

开始之前

会基础 Python 就能开始。矩阵乘法、偏导数和 NumPy 的 shape 操作用到时现补也来得及；全部内容只用 CPU 就能跑完。

你会做出什么一个手写的 NumPy 深度学习库，一个在 CIFAR-100 上训练的 NumPy ResNet，一个带 RoPE、GQA 和 KV Cache 的 PyTorch Transformer。
需要多少时间半小时可以读完三章主线，三个小时够跑通 Block 1 的四个练习，全部实现完是一门完整课程的量。
